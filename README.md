# Happy Birthday, De Milla ❤️

Website kejutan ulang tahun untuk De Milla.

## Struktur

- `index.html` — halaman utama
- `media/chat-01.mp4` — riwayat chat/video bagian 1 (dikompres agar cocok untuk GitHub)
- `media/chat-02.mp4` — riwayat chat/video bagian 2
- `media/chat-03.mp4` — riwayat chat/video bagian 3
- `media/de-milla-voice.m4a` — audio dari video pertama
- `media/happy-birthday.mp3` — musik Happy Birthday

## Cara upload ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload `index.html`, folder `media/`, dan `README.md`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan, lalu buka URL GitHub Pages yang diberikan GitHub.

Penting: jangan memindahkan atau mengganti nama file di folder `media/` tanpa mengubah path yang sama di `index.html`.
